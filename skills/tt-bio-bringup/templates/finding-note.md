# <one-line title stating the mechanism, not the symptom>

Date:
Where it bit:

**Symptom.** What it looked like from outside, in the words you would have used at the time.

**Mechanism.** Why it actually happened. One or two sentences. If you cannot write this, the
investigation is not finished.

**Detection.** The command or observation that confirms it, so the next person can check in a minute
instead of a day.

**Fix.** What was changed.

**Guard.** The test, assertion or check that now stops it recurring, and the proof that the guard
goes red when the bug is reintroduced.

**Generalization.** What class of bug this belongs to, and where else that class could be hiding.
This line is the reason the note is worth writing.
